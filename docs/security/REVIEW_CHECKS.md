# 编辑 AI 预审检查项

适用版本：0.6.833。

桌面安全方案的“预审检查项”旁点击“编辑”，左侧选择检查项，右侧修改名称与检查内容。列表旁的小开关控制启用状态，样式与“专家团定义”一致。支持新增或删除检查项；预置项可单独还原或全部还原。保存前可取消。

“拒绝规则”和“自动放行”的四类规则同样采用左侧名称、右侧表单。分类开关独立控制对应规则是否生效；关闭时仍可编辑，恢复默认沿用已有规则语义。窄窗口中列表与表单顺序排列。

移动端从对话设置的安全方案旁进入“设置”，选择方案后可以编辑同一组检查项、规则、补充说明、预审模型与超时。全权限预置方案保持只读；保存沿用配置版本检查，过期设置需要刷新。

勾选内容参与实际预审，被删除项不参与。自定义项保存到安全方案，桌面与移动端读取同一份设置。直接拒绝或允许规则仍先于预审生效，预审失败或超时转人工。
