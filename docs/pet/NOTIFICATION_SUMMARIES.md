# 通知气泡的可读摘要

适用于 0.6.848。定时任务完成后，宠物气泡和本地系统通知显示可读摘要；完整 Markdown 结果继续保存在原任务执行记录和对话中。点击宠物消息或“在主窗口打开”按钮，仍通过原通知标识打开对应执行对话。

## 内容与长度

- 本地系统通知采用最多 100 个可见字符的单行摘要。
- 宠物气泡采用最多 280 个可见字符的多行摘要，保留段落与列表行。
- 标题、粗体、斜体、引用、链接和代码围栏不再显示 Markdown 格式标记；链接与图片保留可读名称，内联代码和代码块保留正文。
- 列表使用 `•`，任务复选框保留完成/待办标识；表格将每行转成“列名：值”，保持数据关系。
- 内容超过长度时优先选择完整句或行，其次采用单词边界；必须在句中截断时保留省略号。组合 emoji 不从中间截断。

例如：

```text
**北京时间** 10:30

- 项目构建完成。
- [查看报告](private/report.md)
```

宠物显示：

```text
北京时间 10:30

• 项目构建完成。
• 查看报告
```

摘要是纯文本预览，不执行 HTML、不请求链接，也不加载完整 Markdown 或图表渲染器。此转换针对通知中的常见 Markdown；完整排版、图片、代码和流程图仍以对应对话为准。系统通知与宠物开关继续独立生效；执行失败显示失败提示，不用失败回复冒充完成结果。

## 验证

- `node scripts/test-notification-summary.cjs`：强调、标题、引用、列表、链接、代码、表格、Unicode、合理截断及原内容保留。
- `node scripts/test-pet-notifications.cjs`：真实定时通知函数的隔离夹具，验证两种摘要、开关、失败/空结果及原任务点击路由。
- `node --experimental-strip-types scripts/test-pet.mts` 与 `node scripts/test-pet-ui.cjs`：摘要在实际宠物组件显示、通知优先级、按通知标识打开完整内容与关闭行为。

测试均使用虚构内容和投递桩，不发送真实通知或接触用户账号。
