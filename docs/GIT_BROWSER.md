# Git 仓库浏览

启用项目的 Git 插件后，侧栏按根目录和子目录仓库展示 Branches、Remotes、Tags、Stashes 和 Submodules。包含斜杠的分支按目录分组；未管理目录提供初始化入口。

点击分支、远程引用或标签会打开对应仓库的历史标签页，并选中该引用指向的提交，不会执行 checkout。历史列表按页读取，目标不在首屏数据中时继续加载并定位。点击提交行在下半区显示详情；右上角按钮将详情打开为独立标签页。

- Commit：作者、邮箱、时间、引用、SHA、父提交、说明及改动文件。Expand All 展开全部文件的统一差异，单文件右箭头定位到 Changes。
- Changes：可搜索的改动文件树；支持并排和统一差异、行号及代码高亮。
- File Tree：读取所选提交完整文件树和历史文件内容，不读取工作区当前版本。

完全相同的仓库/引用标签页复用，不同仓库的同名分支和同一 SHA 分开保存。Fetch、Pull、Push 仅在点击相应按钮时执行。

初始提交相对空树，合并提交默认相对第一个父提交；重命名同时纳入旧路径。二进制或超过 2 MiB 的文件显示说明。差异加载最多同时执行四个请求，切换提交时丢弃过期结果。

验证：`node scripts/test-git-browser.cjs` 使用独立临时仓库覆盖引用、分页、Stash、子模块、初始提交、重命名、删除和历史文件读取；`scripts/test-git-browser-ui.cjs` 使用隔离 Electron 验证完整浏览交互。
# 滚动与筛选（0.6.527）

提交历史接近底部时自动加载下一批 300 条，不再显示“加载更多”。
同一时间只发起一次分页请求；不足一批时停止，失败时暂停，可用刷新按钮重试。

历史页顶部不再放漏斗。侧栏分支名用于定位该分支提交，展示全部历史；
侧栏漏斗用于按该分支与同名本地/远程关联引用筛选。分组漏斗按组内引用筛选。
漏斗的按下状态须匹配完整引用集，再点取消；筛选横幅也能清除。
取消后再次使用同一筛选标签，会重新应用筛选条件，不会保留失效状态。


## 分支菜单与弹层（0.6.563）

分支切换后仅更新当前勾选和样式，不将当前分支置顶，目录和名称顺序保持稳定。分支菜单使用 12px 字体与紧凑间距，长分支名悬停显示完整操作名称。Git 菜单与对话框中英文词条位于 `src/plugins/git/locales/`，随应用语言切换。

公共光标弹层按真实尺寸优先向下展开，放不下则向上；上下均不足时选择边缘距离触发位置更近的有效位置，超长内容内部滚动。菜单尺寸或窗口大小变化时重新计算。模型/字体选择、对话操作、标题栏面板、翻译、验证详情等复用该规则；需要确认的模态对话框保持居中。

## 固定启用与侧栏入口（0.6.564）

Git 与内置浏览器始终全局启用，不再提供全局/项目停用或“更多”菜单。历史停用配置不影响运行，宿主依赖检查同样视为已启用。0.6.790 已移除 Git/Browser 的“左栏快捷按钮”配置和可见性开关；历史值不再影响入口。侧栏仍可通过工作区布局展开或收起。

字体预览随界面语言切换；系统字体列表排除缺少基本拉丁字母与数字字形的符号字体。

## PDF 打开（0.6.565）

从文件树或本地文件链接打开 PDF 时，使用内置浏览器标签页与 Chromium PDF 查看器，不按文本读取。若当前宿主未提供内置浏览器，则显式选择 macOS 默认网页浏览器打开，而非调用默认 PDF 应用。文件路径先校验并编码，拒绝越出项目的路径与符号链接。浏览器快捷按钮隐藏不影响 PDF 打开。

## 0.6.790 操作与恢复

Fetch/Pull/Push 使用共享仓库锁，pull 只允许快进；首次推送可选远程并设置上游。提交历史的检出/建分支使用程序内弹窗。
工作区支持暂存、取消暂存与仅提交暂存内容；失败保留提交说明。修复新仓库取消暂存、重命名路径、冲突状态与缓存失效。
完整操作与故障步骤见 [Git 帮助](HELP.zh-CN.md#git-plugin) 和 [冲突恢复](HELP.zh-CN.md#git-recovery)。
