# local.notes

中文：在 Sage 全局插件配置中打开测试项目，点击加载开发目录选择本目录。检查权限后测试服务。可从开发插件的更多菜单导出含依赖包。详细说明和验收步骤见 PLUGIN_MANUAL.md 第 12 节。

English: Open a test project in Sage, then load this source folder from global plugin settings. Review permissions and test the service. Export with dependencies from the development plugin menu. See section 12 of PLUGIN_MANUAL.en.md for instructions and acceptance steps.

此示例无需 npm 依赖。SDK 类型文件仅供编辑器使用。
No npm dependencies are required. The SDK declaration file is for editor checking only.
