# 安全与授权配置

设计参考 [OpenAI 的沙箱与审批分层](https://learn.chatgpt.com/docs/agent-approvals-security)：沙箱决定实际能力，审批决定操作何时可以执行。界面采用用户提供的参考图中的精简预设菜单，并按 Sage 已实现的能力展示选项。

## 两个入口，一份项目策略

- 设置 → 当前项目 → 安全与授权。
- 对话输入框右下角 → 请求批准 / 帮我批准 / 自定义。

两个入口编辑同一份项目策略，对普通会话和专家任务生效。配置会自动保存；保存失败时显示错误并可重试。安全配置独立保存，关闭外层通用设置不会撤销已保存的安全配置。

## 配置内容

1. **执行边界**：确认命令沙箱、文件保护和禁网限制。当前命令运行时仅支持 macOS；不可用时停止执行。此页是能力说明，不提供无效的关闭沙箱或联网开关。文件工具由文件策略控制，手动终端不属于 AI 命令沙箱。
2. **需要审核**：选择人工或 AI。AI 预审可勾选预设检查项，在其下填写其他预审说明，并单独选择模型和超时。检查项、说明和操作证据合并为一次模型请求。色块覆盖整个 AI 预审区域，包括最后的说明。失败、超时或无法确认时转人工。旧版允许、禁止和补充说明均保留；合并后总上限为 24064 字，包含分隔与标签。
3. **批准范围**：独立选择项目文件修改、限定本地构建是否自动通过。更改后自动保存。

| 预设 | 项目文件修改 | 限定构建 | 未知命令 |
| --- | --- | --- | --- |
| 请求批准 | 人工 | 人工 | 人工 |
| 帮我批准 | 自动 | 自动 | AI 预审，不确定转人工 |
| 自定义 | 按已保存配置 | 按已保存配置 | 按已保存配置 |

项目内读取和搜索自动通过，但仍先进行路径检查。WebFetch、其他网络或未知工具需要人工确认。未知工具使用同一预审入口；域名规则与命令联网的运行时范围仍分别检查。任何模式均不关闭硬约束和运行时沙箱。

预设保留已有自然语言策略及高级规则，不删除路径保护或域名设置。首次选择「帮我批准」且没有授权说明时填入本地开发示例，可以继续编辑。

## 高级规则与诊断

默认折叠文件保护、工具环境、命令规则和网页访问。默认列表直接从执行器读取，避免维护两份默认值。每行一条，自定义替换该字段；清空/恢复默认后继承执行器默认值。保存时去除空行和完全重复的行，保留路径和正则的大小写。无效命令正则不能保存。

- PATH 只影响工具发现，不授予额外的文件或网络权限。
- WebFetch 域名规则不会开放 Bash、npm、Git 的网络。
- 自定义文件保护不能解除运行时固定保护（凭证、安全配置、Git 钩子等）。
- 「决策记录」可筛选待审核、批准、放行和拒绝；「请求监控」记录 AI 预审调用。

批准范围只覆盖 `npm run build`、`build:renderer`、`build:electron` 的受限构建，不能代替安装依赖、发布或 DMG 系统打包需要的额外能力。

## 旧逻辑清理与兼容

旧会话的 `requireApproval`、`preApprovedTools` 不再控制普通会话与专家任务。CLI 会话固定使用 SDK 默认权限，并通过 Sage 的审批入口；不再暴露相互冲突的 SDK 权限下拉框。历史字段仍可保留在数据文件中供兼容读取，不需要批量改写历史会话。

项目未保存过 `review.projectFiles` 时，兼容旧的全局 `autoApproveProjectScope`；分步配置保存后显式写入项目选项，优先级高于旧全局值。已有自然语言说明、模型选择和高级规则保留。

删除了旧工具记忆授权栏、免审批动作、重复的 Bash 项目路径启发式、前端硬编码默认规则、旧帮助/放大编辑组件及相关样式。拒绝提示跳转到同一配置入口，取消原先直接追加域名且可能覆盖默认列表的快捷按钮。

## 验证

- `node scripts/test-security-settings.cjs`：菜单和设置共用策略，检查项保存、旧说明迁移、完整 AI 预审区域、空配置校验，保存失败/重试，执行器默认值、大小写保留。
- `node scripts/test-sandbox-review.cjs`：历史误拒绝、预审及凭据，项目文件范围优先级，Bash/网络不走文件自动批准。
- `node scripts/test-runtime-sandbox.cjs`：真实 macOS 沙箱文件/网络/子进程边界。
- `node scripts/test-security-electron.cjs`：独立 Electron 视觉夹具，需要可用的 Electron；也可用 `--browser` 生成隔离的浏览器夹具，或 `SAGE_TEST_ELECTRON` 指定本地测试运行时。
- `npm run typecheck` 与 `npm run build`。
