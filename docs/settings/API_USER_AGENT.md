# API 直连 User-Agent

适用：Sage 0.6.826 起。

## 使用

在全局设置的「后端引擎」选择「API 直连」，执行方式右侧显示 User-Agent 选择框。窗口较窄时控件自动换行。

| 选项 | 请求头 |
| --- | --- |
| Sage（默认） | `sage/当前应用版本 (api mode)` |
| Claude CLI | `claude-cli/检测到的版本 (external, cli)` |
| Codex CLI | `codex-cli/检测到的版本` |
| 自定义 | 自己填写，例如 `my-user-agent` |

CLI 版本通过配置的可执行文件或 PATH 上的 `claude` / `codex` 的 `--version` 获取，界面和请求头共享主进程的解析结果。检测没有使用 shell，最长等待 1.5 秒，成功结果缓存 5 分钟，失败结果缓存 30 秒；未安装或检测失败时分别使用兼容身份 `2.0.14` / `0.159.0`，API 直连不要求安装 CLI。

设置自动保存。切换到 CLI 引擎时隐藏此控件，切回 API 保留选择和自定义内容。自定义值支持最多 512 个可打印 ASCII 字符，发送时移除首尾空格；空值回退到默认 Sage 身份。非法输入显示提示，不覆盖上次有效保存值。

该设置应用于新创建的直接 API 客户端，包括对话、计划、摘要、图片分析、专家请求、提供商连接和模型检测、AI 预审。已有请求继续使用创建客户端时的设置。CLI 引擎和软件更新下载使用各自的请求头。

## 开发和检查

所有请求头接入均维护在 TypeScript 源码，开发模式和正式构建不需要修改编译产物的补丁。

```sh
npm run test:api-user-agent
npm run typecheck
```

回归测试检查实际 Anthropic/OpenAI HTTP 请求头、鉴权保留、版本检测和回退、设置校验与持久化、备份分组、界面自动保存与引擎切换，以及所有 SDK 构造的覆盖。
