# 定时任务：统一对话与执行记录

适用版本：0.6.859。

在普通 API 对话中描述任务，例如“每天 9 点检查项目，结果发回这里”。模型会通过 ScheduledTask 工具提出确认卡片；核对任务提示词、时间、模型、思考强度和输出方式后保存。取消不会创建任务。同一对话可以持续修改任务；修改期间发生其他更新会要求重新确认，避免覆盖。

推荐案例首次进入展开，之后默认收起，可通过页面顶部“推荐案例”按钮重新展开。

任务管理页提供“新建定时任务”配置弹窗及 9 个分类推荐案例。案例只预填名称、提示词和时间，保存后才创建；弹窗复用主模型与思考强度组件。页面分为我的定时任务和执行记录，保留配置编辑、立即运行、暂停/启用、删除与记录筛选，不维护独立对话窗口。“在对话中创建/调整”进入普通对话。对话式确认工具适用于内置 API 引擎；第三方引擎需要接入对应工具协议。任务执行统一使用 API 模型，因此需要可用的模型提供商。

## 来源消息与修改反馈

任务卡片的对话按钮定位并高亮创建任务的消息；旧任务尝试从来源对话的 ScheduledTask 成功记录定位。找不到来源消息或来源已归档时，新建管理对话并持久保存关联，后续点击复用。已有对话草稿不会被覆盖。新任务保存来源消息 ID，编辑任务保留原始来源。

通过对话确认修改后，消息中直接显示成功、取消或失败反馈；成功修改可展开查看各项配置的前后变化，失败不会显示保存成功。

## 输出方式

- 指定对话：新建任务默认选择关联对话；没有可关联对话时，在保存任务时新建一个，后续执行复用。每次完成后追加回答；执行过程在独立审计对话中进行，避免覆盖正在进行的聊天。
- 新对话：每次执行保留一个新结果对话。
- 渠道：投递到勾选的已启用渠道，执行错误与投递错误分别记录。
- 静默执行：成功时不追加聊天回答、不发系统通知或渠道消息；仍保存执行记录，供展开检查。执行或投递失败按提醒开关提示。

有任务的顶部对话标签显示简洁沙漏；侧栏标题前不重复显示，尾部和顶部 Tab 在任务启用时持续显示流沙翻转动画，包括等待下次执行期间；停用或最近执行失败时显示红色。普通状态沿用所在区域图标颜色，侧栏悬浮时让位于菜单按钮。遵循系统减少动态效果设置。对话中默认折叠显示“定时任务已执行 X 次，失败 X 次”，展开查看时间、状态、错误和详情。失败数包含投递失败。

## 归档与暂停

归档对话时暂停来源或输出关联的定时任务，保留配置和历史，不再触发下一次执行。已经开始的执行允许结束并保存记录，结果不追加到已归档对话。恢复对话不会自动恢复任务，用户需明确启用。旧任务关联的输出对话已删除或归档时，加载及执行前检查会自动暂停，页面显示原因；修复关联后手动启用，历史失败记录保持原样。

## 时间、模型与可靠性

使用本机时区，支持一次性、间隔、每小时、每日、每周和每月。Sage 必须运行；休眠/退出期间不执行，恢复后逾期周期合并为一次，不重放所有错过的次数。一次性任务触发后停用。手动执行不改变下次计划。

任务可选择模型及思考强度，也可跟随项目/全局默认。明确选择的模型不可用时记录失败，不静默换成其他模型。无人值守运行仍经过工具审批策略；无法进行额外人工授权的操作不会自动批准。超时范围 1–120 分钟，默认 30 分钟。

任务写入按项目串行化，任务和运行记录通过临时文件原子替换。相同任务禁止重叠执行；运行中修改时间或暂停，旧运行结束不会覆盖新设置。重启后发现未完成的运行会标记失败，不伪报成功。旧任务有可用结果对话时继续关联该对话，已有渠道配置继续保留。

## 设计参考

参考 [ChatGPT Tasks](https://help.openai.com/en/articles/10291617-scheduled-tasks-in-chatgpt) 的对话创建与集中管理方式，以及 [Claude Cowork scheduled tasks](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-claude-cowork) 的桌面执行边界。Sage 的输出方式、模型配置和执行记录以本页实现说明为准。

## 无人值守任务授权（0.6.706）

在新建或编辑任务的「模型与思考强度」下方，通过「授权方案」选择该任务使用的安全方案，样式与聊天授权选择器一致。支持“跟随默认方案”和已启用的具体方案；完全访问权限沿用确认弹窗。保存后只影响该任务后续运行，不会修改全局默认或正在执行的任务。

每次运行读取所选方案的最新规则，先确定方案再加入来源对话背景。未配置的旧任务跟随默认方案；显式选择的方案若被删除或禁用，记录失败并要求重新选择，不静默换成其他方案。普通对话的一次性许可不会继承。

若执行记录提示需要人工审批：编辑该定时任务，在「授权方案 → 管理方案」中编辑所选方案，在「直接允许 → 命令规则 → 允许命令（正则表达式）」中按实际需求添加精确规则，并确认命令规则已启用，再手动运行一次任务验证。不要添加匹配所有命令的规则。修改方案规则也影响其他使用该方案的对话与定时任务；可以新建专用方案隔离授权范围。

项目内单独执行的 `git status`、`git log`、`git diff` 已有内置只读规则；带额外前缀、管道或复合操作的命令可能仍需审批。先在安全决策记录中查看具体命令与拒绝原因；直接拒绝规则优先，不应为了运行任务关闭全部安全检查。

从 0.6.768 起，需要人工审批时任务保持运行并显示“等待授权”。任务卡片和执行记录显示具体工具、参数及“同意本次并继续 / 拒绝”。同意只放行这次操作，不改变授权方案；拒绝标记失败。等待计入任务超时，超时或重启后旧审批失效，不能补点同意。旧版已失败的任务需点击“立即运行”，在新的审批点继续。完全无人值守仍应提前配置最小必要权限。

### 内网健康检查的授权示例

若仅需要请求服务接口，可创建专用方案，在「直接允许 → 网页访问 → WebFetch 允许的域名」中逐行加入目标主机和端口，例如：

```text
192.168.1.71:52415
192.168.1.72:52415
192.168.1.73:52415
192.168.1.74:52415
```

任务内容中明确使用 WebFetch 访问对应 HTTP 接口，再为任务选择该方案。这里填写主机与端口，不是 CIDR 网段。现有规则显式允许这些内网主机后才会解除 WebFetch 的内网地址拦截。

Bash 中的 `curl` 与 WebFetch 是不同的权限通道：即使网站已放行，沙箱命令仍默认不能联网；“保留沙箱，联网单独审批”需要人工批准，不能用于完全无人值守。若确实要让任务直接运行联网命令，可显式选择“完全访问权限”并确认其范围；该方案同时开放文件和命令权限，不仅是网络。

## 失败提示的展示（0.6.707）

单次执行的失败只在对应任务卡片显示简短摘要，详细原因默认折叠；授权失败可直接点击“调整授权”。立即运行返回的已记录失败不再同时出现在页面顶部。重新运行时隐藏旧失败摘要，新结果取代它；执行记录保留历史详情。页面加载或全局设置失败仍会在页面顶部提示。

完全访问权限的二次确认显示在任务编辑窗口上方；取消只关闭确认，确认后仍需保存任务。


## 执行记录与对话列表（0.6.767）

后台执行使用独立的内部工作对话，仅从定时任务的执行记录中查看，不进入普通对话或归档列表。只有明确选择新建对话输出时，成功执行才发布为普通对话；勾选关联对话时只向目标投递结果。

旧版产生的内部对话按运行记录、任务关联和系统生成的执行指令识别并从列表隐藏，内容不删除。来源/目标对话、明确的新建对话输出以及追加过人工消息的历史对话保留；无法可靠关联的旧记录保持原样。归档内部执行记录不会停止定时任务，需要在任务配置中关闭启用。


### 人工审批设计参考

参考 [LangChain HITL](https://docs.langchain.com/oss/javascript/langchain/human-in-the-loop) 和 [n8n 工具人工审批](https://docs.n8n.io/advanced-ai/human-in-the-loop-tools)：在实际工具调用前设置审批点，按操作逐项决策，展示真实参数，区分一次批准与长期策略。Sage 的任务运行记录保存待审批状态和决策时间；支持等待授权筛选、并发请求逐项审批、过期及重复响应拒绝。

当前实现可在应用保持运行时原地继续。重启时将未完成运行标记失败并使旧审批失效，保留执行详情供检查；不承诺跨进程恢复或外部操作恰好执行一次。重新运行前应检查此前已执行的步骤。

## 导入与导出任务配置（0.6.770）

任务列表顶部可导入 `.sage-task.json`，每张任务卡片可导出当前配置。导入会校验文件格式并打开任务编辑窗口供确认，保存后默认暂停，避免刚导入就自动执行。来源对话不会导出；不存在于当前项目的关联对话需要重新选择。文件只包含任务配置，不包含运行历史。

## 0.6.790 来源授权快照

对话创建的新任务默认继承来源安全方案与可重复批准的具体调用。任务只复用工具名和完整参数匹配的授权；不复制无限未来授权、一次性凭证或操作系统权限。
保存时绑定来源项目、方案内容、启用插件代码/权限/配置和 MCP 配置摘要。运行时任何绑定变化均要求检查并重新保存，暂停/启用不自动扩大授权。输出子步骤与主步骤使用同一个受限执行上下文。
导出模板不包含授权快照；导入默认暂停并使用独立方案。详见 [授权继承帮助](HELP.zh-CN.md#scheduled-authorization)。

## 无更新时只保留原始执行记录（0.6.850）

条件监控任务未达到用户指定的播报条件时，不再向结果对话、渠道、系统通知或宠物气泡重复发送“静默结束”“无新消息”。静默运行依然计入执行次数，在来源对话展开“定时任务已执行…”可看到“静默完成”，点击“执行详情”查看完整过程、工具和原始结果；也可从任务页进入对应执行记录。原有历史消息不会被删除，任务的提示词、时间、输出配置不会被自动修改。

调度器要求模型用末行 `[[SAGE_SCHEDULED_OUTPUT:silent]]` 表达不需要播报，用 `[[SAGE_SCHEDULED_OUTPUT:notify]]` 表达需要投递；该控制行不会出现在投递消息中。没有标记的正常输出继续投递，仅对少量完整、短格式的旧版无更新状态做兼容；正文中提到“无新消息”或“静默”不会被删除。空的最终回答只保留执行记录。

执行错误、授权被拒绝、超时和投递失败独立记录，不能被静默标记隐藏；有意义的变化与告警仍按配置正常投递。来源/结果对话归档后的暂停和只读规则保持不变。手机接收任务状态变化提示后重新读取经过授权的持久化提醒；提示中不携带执行正文。

## 检查进展与提醒结果（0.6.856）

每轮执行使用独立的内部执行对话，保留工具调用、进展说明与最终回答。在任务列表查看最近检查时间和状态，点击「运行记录」查看详情；来源对话及实际输出对话的折叠任务活动也可进入记录。手机的任务行提供「记录」入口，自动执行状态来自桌面保存的真实运行记录。静默完成显示「未触发提醒」，不由这一状态推断监测对象一定没有变化。

工具执行前的进展文字与最终回答分别处理。对话、通知渠道及桌面通知只使用最终回答；纯进展、空的最终回答及按任务规则静默结束的执行不追加结果消息。明确选择新建对话输出时，新对话仅保留待投递的最终结果，原始执行记录仍独立保留。

任务执行指令要求模型在最终回答末尾单独输出 `[[SAGE_SCHEDULED_OUTPUT:silent]]` 或 `[[SAGE_SCHEDULED_OUTPUT:notify]]`，调度器投递前移除控制行。条件不满足、例行检查未产生需提醒结果时使用 `silent`；需要用户关注的变化使用 `notify`。旧模型没有输出控制行时保留正常结果兼容，对少量完整且明确的旧「无新消息」文案兼容静默处理，不按任意正文中的「无变化」词语屏蔽结果。

执行失败、超时、拒绝授权、截断或未完成的模型轮次不会标记为静默成功。检查过程和投递状态可追踪，但软件无法代替模型核实监测内容；提示词中应明确需要提醒的条件。静默执行不推进结果对话的未读状态。

## 手机编辑结果处理流程（0.6.859）

手机任务编辑页提供主任务多个输出目标，以及「条件判断与后续处理」的步骤编辑。步骤可选择主任务及此前步骤作为来源，多个来源全部命中才继续；通知渠道必须已启用。沿用桌面端流程执行和任务授权，手机保存不会扩展权限。没有主任务目标时保留内部执行记录，条件步骤仍可按各自目标投递。

修改旧任务时保留未编辑的流程字段和旧版 `parentId` 关联，编辑来源后使用多来源配置；删除步骤时修复其后引用，避免保存悬空关联。桌面同时修改任务时，手机通过原有更新时间校验阻止覆盖。畸形流程配置在写入前报验证错误，不会崩溃或部分保存。


### 手机案例、管理与桌面唤醒（0.6.859）

手机和桌面共用九个推荐案例及四类筛选；「使用案例」先进入可编辑草稿，不自动执行。导入 JSON 进入暂停的独立授权草稿，不带入来源授权；导出通过系统分享配置文件，不包含运行历史或凭据。手机工具栏提供「在对话中创建」，卡片提供关联对话、运行记录及导出。

关联对话优先使用同项目内现有来源或实际输出目标。独立方案任务无关联时创建含任务上下文的管理对话并按更新时间关联，不自动发送、不覆盖现有输入；继承来源授权的任务若来源失效，要求显式重选，不能暗中扩大授权。重复点击与超时重试复用同一次宿主处理。

手机「保持系统唤醒」控制运行任务的桌面电脑，与桌面设置共用真实电源保持入口；仅修改这一项，不更改手机屏幕休眠设置。旧桌面未提供接口时需升级。暂停任务的前置状态图标隐藏，运行记录仍可查看。

### 工具迭代上限与错误查看（0.6.859）

“工具调用达到轮次上限，尚未生成最终结果”表示任务已经用完 API 引擎的模型执行轮数，仍没有返回最终回复。默认 `maxAgenticIterations` 为 50；一轮可能包含多个工具调用。该上限与任务的分钟超时、模型上下文和套餐 Token 配额分别控制不同边界。应先在执行详情查看重复抓取、重试、工具失败或任务范围过大；不要把未完成的过程文本当作成功结果。可在运行时设置中调整上限，但提高上限不能解决循环调用。

任务卡片和执行记录提供中文摘要与展开解释，普通错误不重复同一句摘要和正文。任务历史和详情弹窗允许截屏快捷键；快捷键录制时仍不执行截屏，弹窗内不触发语音录制。
