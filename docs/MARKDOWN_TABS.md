# Markdown 标签页名称

0.6.536 起，`.md`、`.mdx` 文件的标签页优先使用正文中第一个非空一级标题（`# 标题` 或 Setext 的 `===` 标题）。没有一级标题、二进制文件或非 Markdown 文件仍使用文件名。

标题通过 Markdown 解析器提取纯文本，支持加粗、链接、行内代码等；不读取代码块、引用、HTML 注释或开头 YAML frontmatter 中的伪标题。不执行 HTML。为避免大文件阻塞界面，只解析文档开头 64 KiB 字符范围，并缓存未变化的文件对象。

这仅影响标签页文字，不改文件路径、文件名、文件图标、固定状态、未保存提示和关闭行为。悬停同时显示完整标题与文件路径，长标题沿用标签页的省略显示。编辑或重新加载正文后标题同步更新，移除标题则回退到文件名。
