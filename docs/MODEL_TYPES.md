# 模型类型检测与展示

模型选择器和提供商的模型列表共用类型缓存，只显示接口已确认支持的类型。未确认、不支持的类型不显示图标，不使用名称猜测补齐；过滤也仅匹配已确认类型。

| 类型 | 图标 | 确认证据 |
| --- | --- | --- |
| Vision / 视觉 | Eye | 正确识别有效 64×64 PNG 的上下色块；普通成功响应不作为视觉能力证据 |
| Web Search / 联网搜索 | Globe | 返回搜索工具结果或 URL 引用 |
| Reasoning / 推理 | Lightbulb | 返回 reasoning 或 thinking 内容 |
| Tool / 工具调用 | Wrench | 实际调用探测函数，不仅是接受 tools 参数 |
| Reranker / 重排 | ListOrdered | rerank 接口返回带索引和相关度的排序结果 |
| Embedding / 向量嵌入 | 芯片与代码 | embeddings 接口返回非空向量 |

## 全局缓存

- 缓存位于应用数据目录的 `model-capability-cache.json`，格式版本 4，记录去除凭证和查询参数的接口地址，不包含密钥。
- 按原始模型 ID 全局去重。中继使用服务端返回的原始模型名称，不使用带渠道的展示名称或路由 ID。版本、命名空间和量化后缀不折叠，避免误认成同一个模型。
- 同名的不同提供商随机选择一个执行一轮接口测试。复合提供商不单独测试，以同名模型缓存显示；不同名称的别名不会被猜测为同一模型。
- 已确认字段持久保留，不重复测试。旧版按提供商的缓存判定不可靠，首次升级重新检测。

## 调度与边界

- 启动后后台检测，每分钟轮询，每批最多 3 个模型，跨窗口共享单个执行队列。界面读本地缓存，不等待网络测试。
- 未确认字段按 10 分钟起指数退避，最长 24 小时。每次重试可选另一可用提供商，已确认字段不重测。
- 认证失败、限流、超时、通用参数错误、接口缺失或提供商限制不能全局判定为“不支持”。只有明确的模型能力拒绝才记为否；阴性结果不在选择器中显示图标，但在验证汇总表中显示“不支持”。
- OpenAI-compatible 和 Anthropic Messages 使用各自接口。非标准协议、无法返回验证证据的能力保持未确认；未知不等于不支持。
- 检测会产生少量真实请求，可能产生提供商费用。普通探测限制输出 128 个词元，推理探测使用协议要求的最小预算，搜索至多请求一次工具使用。每个请求最多等待 12 秒。
- 当前类型表示模型在所选接口上的能力证据，不保证每一个提供商都开放相同功能。对会改变底层模型的同名别名，需要重新清理缓存后检测。


## 验证汇总（0.6.560 起）

提供商管理下方按模型、类型、是否支持、验证提供商、验证时间展示全部记录。支持搜索、仅看未验证、逐项重新验证及重试全部未验证项。后者绕过自动退避与每批三个模型限制，串行执行、显示进度，不重复验证已确认类型。旧记录没有来源和时间时显示“未记录”。

## 中继共享（0.6.561 起）

配置并连接已升级的中继后，客户端先读取中继共享结果，并将本机已有明确结果补充到中继。以原始模型名称和类型作为共享键，保留大小写、版本、命名空间和量化后缀。同名模型一次验证后，其他客户端无需再次调用模型接口；中继缓存不按客户端隔离。

自动检测在启动、连接中继及每分钟调度时先同步缓存。未配置中继、连接未建立或旧服务返回 404/405 时继续使用本地能力；新中继接口暂时不可用时保留本地结果，不绕过共享锁启动新的重复探测。

验证前领取 90 秒短期锁。同一模型类型同时只有一个客户端获得锁；进程退出或请求丢失后锁会超时释放。未知结果释放锁但不写成“不支持”。逐项 reload 属于显式重新验证，可替换已确认缓存；普通补充上传只填空，不覆盖其他客户端已确认结果。离线和旧版本客户端不能参与并发去重。

共享缓存只包含模型、类型、支持布尔值，以及服务端生成的缓存时间，不上传模型请求正文、API Key、客户端 Token、提供商地址或本机提供商名称。桌面汇总中复用的结果标注为“中继共享缓存”，本机验证保留本机提供商记录。共享结果是已认证客户端贡献的能力证据，不保证所有供应商都开放该功能。

服务器提供商后台新增“模型类型共享缓存”页，管理员和有效 Client Token 均可查看。缓存保存于 `data/providers.sqlite`，跟随该数据库备份。接口、验证锁与部署说明见[中继模型类型缓存](website/MODEL_TYPE_CACHE.md)。

0.6.562 起，汇总按模型合并为一行圆形类型图标。支持用对应类型颜色显示，不支持用深灰、未验证用浅灰显示，悬停区分具体状态并展示提供商、时间。双击图标或使用悬浮卡片操作可验证；已有支持或不支持结果均需二次确认。键盘 Enter / 空格也可启动验证，仍遵守相同确认规则。

0.6.569 起，提供商管理右下角的图标按钮控制汇总显示，默认收起。面板关闭时停止汇总轮询，缓存不受影响。汇总只展示六种模型类型，不再显示基础“对话”；从此处批量重试也排除对话类型。标题、说明、筛选、状态、悬浮详情、确认框和中继来源名称支持中英文，验证时间随界面语言格式化。

## 验证日志（0.6.570 起）

类型图标详情中的“验证日志”显示最近 5 次尝试：提供商、协议、时间、耗时、HTTP 状态、请求摘要、响应或错误，以及判定原因。认证、图片格式、网络错误或缺少预期证据仍标为未验证。旧记录没有日志时说明未记录，重新验证后生成。图片与密钥脱敏，日志仅存本地，不上传共享缓存。

旧验证图是损坏的 1×1 PNG，不能用于判断视觉能力。新图为 64×64 RGB PNG，上红下蓝；尺寸也满足[阿里云视觉要求](https://www.alibabacloud.com/help/zh/model-studio/vision)。升级重置旧未知项的退避等待；已有结果需手动重新验证，不按模型名强行标记支持。

验证：`node scripts/test-probe-diagnostics.cjs`、`npm run test:model-types`。
