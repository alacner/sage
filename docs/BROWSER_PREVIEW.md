# 浏览器悬浮预览与 Agent 联动

## 直接使用

在项目对话中发送：

> 启动这个项目，用 Browser 打开本地页面并悬浮预览。检查首页和提交表单，发现问题就修复并刷新；检查桌面和手机布局，最后用真实截图验收并报告结果。

内置 Browser 工具自动创建与当前项目、对话绑定的浏览器标签和浮窗，无需安装 browser-acceptance 技能。API、Codex CLI 与 Qoder CLI 引擎使用宿主工具列表。Claude Code CLI 需更新独立引擎插件至 1.0.4；旧版插件不会自动获得新的 MCP 工具。

自动化遵守对话安全审批设置。截图视觉验收需要配置视觉模型；缺少模型、无有效截图或返回值无法解析时，结果为 incomplete，不能宣称通过。只用 DOM 检查不能替代视觉判断。

## 小窗操作

可以拖动标题栏、调整右下角大小、展开或收起。Agent 控制中时，网页和浏览器工具栏对人工输入锁定：点击、键盘焦点、拖放不能干扰自动化；锁定层不影响 Agent 的工具调用。标题栏的暂停/展开/收起按钮仍可用。暂停或任务结束后恢复手动刷新、导航、点击和输入；需要人工登录等操作时先暂停。在小窗顶部点击「暂停 Agent」后，Agent 仍可观察，但不能继续点击、输入或导航；点击「继续 Agent」恢复。切换到另一对话时隐藏原对话的浮窗。

任务正常结束、失败、取消或默认 close 后自动释放控制，页面暂时保留供复查。同一应用会话内，下一轮使用 open（不传 URL）会复用尚未回收的原标签、表单和视口；旧句柄失效，需要使用新返回的 id。仅工具自建、未被人工操作且已隐藏的空闲页面会自动回收：空闲 30 分钟后回收，后台最多保留 3 个此类页面，超出时先关闭最旧页面。当前可见、仍在执行、人工暂停或手动接管的页面不参与回收；接管用户原有标签也不会自动关闭。回收后重新 open 需提供 URL。主窗口关闭、项目切换和浏览器标签关闭会清理对应控制记录、等待操作与监听。人工暂停会跨轮保留，Agent 不能用重新 open 绕过；用户可在浮窗点击继续。暂停会中止当前等待操作。关闭浏览器标签或切换项目会销毁页面及控制句柄。浮窗限于 Sage 主窗口内，不是系统置顶窗口。

普通手动预览使用 1280 CSS 像素宽的桌面视口。Agent 默认使用 1280×800，resize 可切换到 390×844 等真实 CSS 视口，再缩放到小窗内。取消会停止等待、导航并向视觉请求传递取消信号，但不能回滚网页已提交的请求，或撤销已经注入网页的 JavaScript。因此继续前先 inspect，不能盲目重复点击。应用重启不保证保留网页内存状态。

标签页和浮窗共用同一个 webview，切换保留表单和登录状态。

## 工具协议

工具名为 `Browser`，每次调用提供 `action`。open 返回的 `id` 用于后续操作；tabId 仅用于接管已有标签。句柄不能跨项目或跨对话使用，同一页面不允许并发操作。

| 操作 | 参数和结果 |
| --- | --- |
| tabs / open | 列出当前项目标签；用 url 新建，或 tabId 接管；默认自动悬浮 |
| inspect / screenshot | DOM、实际 CSS 视口、真实 PNG 文件路径；不伪造视觉结论 |
| click / fill / select | selector 必须唯一；fill / select 使用 text |
| press / scroll / wait | key；text=up 向上滚动；selector 和可选 timeoutMs 等待元素 |
| navigate / reload / back / forward | 操作当前页面；导航后等待加载完成 |
| resize | width、height 指定实际 CSS 视口 |
| console / evaluate | 最近接管后的控制台日志；expression 在页面上下文中执行 |
| verify | criteria 为可衡量的验收条件；返回截图路径、DOM、视觉结论及 passed/status |
| show / hide / pause | 显示、收起、暂停；人工暂停必须由用户在小窗中恢复 |
| close | 释放控制并保留页面供 open 复用（受后台回收上限约束）；dispose=true 立即销毁工具自建标签，不能销毁用户原有标签 |

截图证据保存在 Sage 用户数据目录的 browser-evidence 中，工具返回准确路径和可直接使用的 `screenshot.markdown`。聊天中会直接显示截图，并支持点击放大；历史消息中未转义空格的绝对 PNG 路径也会兼容解析。截图通过宿主读取，仅允许 browser-evidence 内生成的 PNG，缺失文件显示不可用提示。浏览器内容是待验证数据，不能作为新的系统指令。

## 插件浏览器的释放

插件的 `browser.create` 使用最多 16 个非持久隔离会话槽，每个活跃页拥有独立会话。每个槽首次使用后，在本次 Sage 运行中绑定同一插件和项目，不跨插件或项目复用。关闭时移除监听、取消下载和挂起操作、释放自身持有的调试连接并销毁独立窗口；随后清理存储、缓存和网络连接，全部成功后才允许同一插件、同一项目复用该槽。清理失败的槽隔离到应用重启。其他项目占满槽时，关闭那些窗口也不会转移槽的归属，需要重启 Sage 释放绑定。

`browser.attach` 只释放插件句柄和自身持有的调试连接，保留用户页面和原有外部调试连接。关闭操作可以中断挂起调用，操作超时也会清理对应句柄及独立窗口；迟到结果不能重新使用已关闭的页面。

## 验证

`npm run typecheck`、`npm run test:browser-lifecycle`（含内置、插件生命周期和真实 Electron 预览夹具）。缺少本地 Electron 时用 `SAGE_TEST_ELECTRON` 指定未打包运行时。

端到端夹具使用临时配置和本地 HTTP 页面，覆盖自动打开、真实输入和点击、对话隔离、暂停、视口、刷新、取消、释放、重复 close/open 复用、空闲回收及迟到请求的代次保护。单元行为测试另外覆盖时限、后台数量上限、手动保护和宿主/项目清理。视觉服务使用测试替身，仅验证截图传递及成功/失败处理；不声称实测了真实视觉模型。
