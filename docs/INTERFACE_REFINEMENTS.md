# 界面交互调整

## 0.6.820 对话输入栏间距

输入栏左侧图标的外侧留白与右侧发送按钮保持一致，净间距均为 12px；能力图标到模型选择框的可见间隔与权限框到麦克风的间隔一致，均为 6px。以现有右侧为基准，保留 27 × 32px 能力按钮点击范围。实际 ChatView 与 CSS 在 860/1280/1848 宽度、1×/2× 下测量通过，点击区无重叠。

## 0.6.705 左栏布局与项目名称

- 拖动对话、文件、Git 等板块的标题栏，放到目标板块上半部或下半部即可调整顺序；标题聚焦后也可按 Alt+↑/↓。按项目保存顺序、展开状态、板块高度及滚动位置，切换项目或重新打开后恢复。临时停用插件不会清除其排序。
- 底部按钮采用更紧凑的间距和点击区域，足够宽时保持一行，真正放不下才换行。
- 左上角最近项目按钮旁显示当前目录名称，悬停查看完整路径；长名称截断。

## 0.6.704 渠道复制与计划浮窗

- 渠道完整回调地址、公共前缀和诊断日志路径统一使用桌面剪贴板兜底；复制失败明确提示。
- 执行计划浮窗按聊天区域宽度计算并限制左右边界，支持窗口与分栏大小变化，不再受底部按钮宽度挤压。

## 0.6.698 停止任务与图表全屏

- 取消任务且没有待执行消息时，不再记录队列失败或显示空队列报错；消息仍保留停止状态。有待执行消息时继续暂停，真实执行错误保留重试机制。
- Mermaid 全屏预览挂载到窗口最外层，覆盖左栏、顶部栏和状态栏，不受聊天容器裁切或定位限制。保持缩放、窗口适配与 Escape 关闭。

## 0.6.697 图片删除按钮位置

- 草稿图片删除按钮向右上角外移 6px，跨在缩略图边缘；保留悬停显示。附件区预留外沿空间，图片自身保持圆角，避免按钮被裁切。

## 0.6.696 置顶对话标记

- 置顶对话左缘增加低饱和度细竖线，未选中时配合轻微背景色区分。选中和悬停继续沿用原有高亮，竖线保持可见；浅色与深色主题均适配。

## 0.6.695 底部状态浮条

- 文件变更与执行计划统一为相同底色、细边框、圆角和高度的浮条。
- 执行计划状态与继续执行按钮共享一个外框，内部细线分隔，保留各自操作和详情浮窗。

## 0.6.694 聊天回归测试修复

- 推荐选项测试通过真实选项按钮操作，验证单选、多选、手动提交和补充回答，不再依赖已移除的快捷按钮。
- 消息耗时与当日时间显示测试使用运行当天的日期，避免固定日期过期后产生误报。

## 0.6.693 输入框图片附件

- 待发送图片整合到输入卡片内部，使用 120px 圆角缩略图；多图换行并限制附件区域高度，避免挤占编辑区域。
- 删除按钮在图片右上角使用黑底白色叉号，悬停图片或键盘聚焦时显示，触屏保留直接操作入口。保留放大预览与单张删除。草稿、已发送消息及排队预览中的图片序号仅悬停对应图片时显示。

## 0.6.692 对话置顶与渠道悬浮状态

- 对话更多菜单增加置顶/取消置顶。置顶对话优先显示，同组保持原有时间顺序；偏好按项目保存在当前设备，重启保留，同项目窗口同步。归档对话继续隐藏，取消置顶恢复正常排序。
- 鼠标移入对话行时渠道图标原位隐藏，由更多菜单接替，与定时状态行为一致，不再向旁边移动。

## 0.6.691 底部工具图标尺寸

- 左栏底部设置、定时任务、分区入口及帮助图标统一从 20px 缩小至 16px，按钮点击范围保持 32px。

## 0.6.690 对话渠道标记

- 对话已配置接收、回复或广播渠道时，在行尾状态区域显示渠道图标，悬浮提示去重后的关联渠道数量。兼容历史渠道字段，取消全部绑定后即时移除。
- 渠道和定时/运行状态并排显示；悬停时为更多菜单留出空间，沿用左栏图标颜色。

## 0.6.689 文件变更提示自动收起

- 任务结束后，文件变更提示在 30 秒无交互后自动收起；运行中、悬停、键盘聚焦或展开文件列表时暂缓，结束交互后重新计时。新的文件变更重新显示；下一轮无变更时仍立即隐藏。Git Changes 中的文件与差异不受影响。

## 0.6.688 对话预览与列表密度

- 对话列表悬浮内容预览恢复跟随主题的卡片外观：浅色模式使用浅底深字，时间保持次要色；普通按钮提示仍为深色快速提示。
- 对话预览停留 600 毫秒才显示，移出、点击、滚动或切换项目即取消。对话行高 32 像素、上下间隔各 1 像素，保持文字大小。

## 0.6.686 思考强度菜单对齐

- 思考强度菜单右边缘与组合选择器右侧强度按钮对齐，继续自动避让窗口边界；模型列表保持左对齐。

## 0.6.685 统一悬浮提示

- 应用内原生 title 提示和快捷键提示统一使用深色圆角、白字与柔和阴影；长路径换行，自动避让窗口边缘。对话标题预览和上下文用量提示同步配色。
- 首次悬浮约 180 毫秒出现，连续浏览按钮约 60 毫秒，键盘聚焦立即显示；移出、点击、滚动、Escape 或失焦时收起。只在存在悬浮目标时观察标题更新，避免闲置时监听消息流 DOM 变动。

## 0.6.684 中性左栏配色

- 对话、文件、Git、浏览器及底部工具栏统一使用中性灰底、柔和灰色选中态和轻量文字层级；深色主题对应使用中性炭灰。
- 分区标题与工具图标适度淡化，搜索框与模式切换减少色块，保留状态语义色和站点图标。所有展开组合沿用同一套样式，拖拽、折叠及项目布局记忆保持原有行为。

## 0.6.683 紧凑导航与项目独立布局

- 标签排列下拉框改为紧凑图标按钮：并列面板表示自由排列，叠层表示同类聚合。点击在两种模式间循环切换，悬浮提示当前模式及下一种模式；继续记住选择。

- 左栏展开区域可拖拽分界调整高度，也可聚焦分界后用上下方向键调整；收起状态、区域比例、总宽度和显示状态按项目独立保存。
- 区域标题仅图标和文字可点击，去掉前导箭头；浏览器新建普通/无痕标签按钮移到标题右侧。
- 对话搜索弹窗左对齐，长标题省略，时间缩小，避免横向溢出。
- 返回最新消息提示使用白底、灰色图形和淡灰边框。
- 定时任务归档相关错误显示可操作的中文提示，并去除内部 IPC 包装信息；归档暂停策略不变。
- Dock 最近项目仅在重名时为所有同名项附加完整路径，唯一名称保持简洁。

## 0.6.682 侧栏默认布局

- 默认仅展开对话区域；文件及已启用的其他区域默认收到底部定时任务右侧，以图标形式保留入口。
- 用户手动展开或收起的选择继续保存；未设置过的区域采用新默认值。文件搜索与定位仍会自动展开文件区域。

## 0.6.681 对话变更汇总与收起导航

- 对话底部展示本轮文件变更汇总，统计完成的 Write/Edit 和 Git 仓库根目录内终端执行所观察到的变更，排除执行前已有且未再次变化的文件。增删行数按工具执行累计，未知统计不伪造；大文件、二进制或超出扫描限额时降级。
- 汇总主体进入 Git 工作区 Changes 标签；只有一个文件时直接定位，展开列表后点击文件也定位对应差异。复用已有工作区标签，重新打开刷新内容。支持已暂存、未暂存、新增文件。
- 汇总保留至本轮结束，查看 Git 或切换标签不会清除；发送下一条消息开始新一轮后隐藏，排队中尚未开始的消息不清除。
- 上翻且下方仍生成消息时显示圆形三点动画；结束生成后显示向下箭头，点击回到底部，短暂显示箭头后淡出。遵循减少动态效果设置。
- 侧栏分区取消横向分隔线；折叠后连标题一起隐藏，对应恢复图标放在底部定时任务按钮右侧，不再占据正文空间。

## 0.6.680 工作区与定时任务

- 侧栏改为对话、文件、Git、浏览器上下分区，可分别折叠；Git 与浏览器按启用和显示设置出现。搜索与定位文件自动展开文件区。
- 标签栏可切换自由排列（默认）或同类聚合，记住选择；返回自由排列恢复原有顺序。固定标签保留颜色，移除大头针。
- Dock 最近项目以项目名为主，路径放辅助行、缩短用户目录和过长路径，悬浮可看完整路径。最后一个项目窗口关闭后，新开首个窗口加载最后使用的项目。
- 推荐案例首次进入展开，后续默认收起；任务页顶部保留入口。新建任务默认输出到关联对话，缺少时保存创建一个并复用。
- 归档暂停关联任务并保留配置和历史，正在执行的任务允许收尾。恢复对话后仍暂停，必须手动启用。旧任务的已归档或丢失输出对话在加载或执行前检查并暂停。

## 0.6.679 任务来源定位与修改反馈

- 任务卡片对话按钮定位并高亮原创建消息，兼容旧工具执行记录；来源消息不存在或已归档时，创建管理对话并保存双向关联，重复点击复用，已有草稿不被覆盖。
- 对话修改任务后，工具记录外直接显示成功、取消或失败反馈，可展开查看确认后各字段的前后变化。

## 0.6.678 定时任务筛选栏

- 移除任务与执行记录工具栏中的项目名称，保留任务、状态筛选和排序。

## 0.6.676 沙漏循环动画

- 移除定时任务对话的文字前缀，保留沙漏；兼容隐藏已有标题中的 `[定时]` / `[Scheduled]`，新结果对话直接使用任务名。

- 侧栏沙漏与加载图标同为 14px，轮廓接近正方形；侧栏与 Tab 统一依据实际运行状态动画，停用或最近执行失败显示红色，其余沿用所在区域颜色。悬浮仍让位于菜单按钮。
