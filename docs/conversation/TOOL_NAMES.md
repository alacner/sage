# 对话中的工具显示名称

对话操作行使用可读的名称。例如 `mcp_dashscope-enhanced-search_search_pro_b0cf33b3ee21` 显示为「网页搜索」。内部服务前缀和生成的哈希不作为主要操作名称展示。

这是展示名称：工具调用、参数、结果、消息标识和授权校验仍使用原始工具 ID。原始标识保留在详情或提示中，便于排查具体服务。

适用：Sage 0.6.827 起。未知工具保留可识别的名称，不按猜测改写实际调用。

工具显示名称由 `shared/tool-display-name.ts` 维护。修改规则后运行 `npm run test:tool-display-name` 检查桌面显示。


0.6.830 恢复对话响应状态、输入框和授权标题的原有助手名称文字；工具名称的可读显示规则继续保留。
