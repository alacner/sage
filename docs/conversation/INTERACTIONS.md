# 对话交互

适用版本：0.6.830。

对话状态、输入框、授权标题以及手机助手信息恢复原有文字。工具显示名称仍使用独立的可读名称规则。

页签栏「+」单击打开新建菜单，双击直接创建对话。当前没有项目时不会创建；创建过程中重复双击不会创建重复对话。

归档成功后关闭该对话的页签，包括固定页签，保留对话记录。归档失败不关闭页签。当前页签关闭后按原有规则切换到相邻页签。其他窗口的归档通知同样同步关闭；解除归档不自动打开页签，主动查看已归档记录仍可保留其页签。

[对话式授权](AUTHORIZATION.md)继续支持回复“允许”“继续执行”及“拒绝”。

API 直连的自定义 User-Agent 输入框位于选择框右侧；窄窗口自动换行，校验和保存规则不变。

拒绝/允许规则的四个分类横向排列，窄窗口换行。目录过滤卡片保留内边距；语言与字体的系统选项统一为“默认（系统）”。渠道回调前缀悬停提示显示完整 URL。

设置中的对话清单使用当前项目缓存先显示记录，再刷新；可选记忆统计失败不再阻断清单，旧搜索结果不能覆盖新搜索，加载失败显示重试入口。

AI 预审请求在监控器中带“AI 预审”标签。预审检查项支持[编辑与还原](../security/REVIEW_CHECKS.md)。

截屏采集与隐藏编辑器加载并行，仍等待真实画面绘制后显示；不使用旧截图缓存。
