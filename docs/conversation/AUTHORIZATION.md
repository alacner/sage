# 对话式授权

从 0.6.829 起，桌面及已连接的 Android/iOS 客户端可在当前对话只有一项工具待授权时发送“允许”“那你允许吧”“继续执行”或“拒绝”。当前操作即时恢复或拒绝，回复保存在对话中，不进入排队，也不新开模型执行轮次。

授权只处理当前请求，不启用永久授权或整段对话的全部工具权限。多项待授权、问题或计划同时等待时，请使用明确对应的卡片。带附件、引用、条件、疑问和包含其它指令的消息仍按普通消息处理。没有待授权操作时，“继续执行”等消息仍交给模型。

重复客户端消息 ID 不会批准下一项请求。归档、安装更新及失效请求不执行授权；手机端仍限制过大的授权内容。渠道入站、工具结果和模型输出不走此确认入口。
