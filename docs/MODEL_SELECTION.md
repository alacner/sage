# 模型选择与思考强度

适用版本：0.6.641 起。

聊天、全局/项目模型、预审、角色生成、摘要和记忆整理使用同一组合控件。空间不足时先隐藏提供商，再隐藏强度文字；图标保持 16px。模型菜单与强度菜单互斥，模型未验证支持思考时隐藏强度区。

全局模型的强度是默认值，未设置时为 low。项目跟随全局，对话跟随项目（无项目则跟随全局），预审默认跟随对话。模型跟随时可单独覆盖强度，并通过独立的“跟随”选项恢复强度继承（菜单仅勾选跟随项，收起后显示实际继承值）。主动选择模型（包括与父级相同的模型）会将全局默认强度作为初始独立值，此时不显示强度继承选项；恢复模型跟随后才重新显示。覆盖强度不会固定父级模型：`SelectedModel.followDefault` 保留跟随关系，空 providerId/modelId 仅用作继承标记，实际调用前解析父级模型。

摘要模型位于摘要生成策略区域内，始终显示，自动和 LLM 策略都使用它；默认跟随全局。记忆整理模型也默认跟随全局，用于“融合所选”的模型整理，生成后仍需检查、保存。已有自动重复清理仍使用确定性规则。角色生成模型位于描述框下方，默认跟随全局。

价格浮窗显示输入、输出、缓存读取的历史采样，横轴按实际时间排列。仅有当前报价时显示三项数据点和价格，不虚构历史曲线。右上角刷新按钮重新请求中继并更新本地缓存，失败保留缓存并提示。浮窗与录音声纹均独立挂载到页面外层，避免滚动容器裁剪；声纹不占布局空间，停止录音即卸载。

## 复合模型活动日期与每日时段

0.6.763 起，在「设置 → 模型提供商 → 复合提供商 → 成员提供商」使用表单配置，无须输入映射表达式。

1. 添加成员时，勾选对外模型，并选择该成员实际调用的模型；两者可以不同名。
2. 在成员映射中，选择「限定日期与时段」，添加每天的生效时段及活动日期范围，两类均支持多段。
3. 选择「非生效时段使用」的替代模型，点击「应用配置」。未应用的改动可以取消。

例如，对外模型 `qwen-plus` 在 `2026/09/28–2026/10/07` 每天 `22:00–08:00` 使用优惠模型，其余时间使用常规模型。活动结束后自动使用替代模型，无须手动删除活动配置。替代模型可来自任意已启用的非复合提供商；相同模型 ID 来自多个提供商时，沿用现有路由的首个匹配来源规则。

日期和时段按运行 Sage 的电脑本地时间判断。同类多段取并集，日期与每日时段取交集；日期包含首尾两天，时段包含开始、不包含结束。跨午夜时段仍要求当前日处于活动日期内，因此活动结束后的次日凌晨不再使用优惠模型。未添加日期范围表示每天，未添加每日时段表示活动日期内全天。至少保留一种限制；切换「不限制时间」并应用会清除日期、时段及替代模型。

不设置替代模型时，范围外跳过该映射，其他可用成员仍参与路由。模型选择器始终保留已配置模型；请求无可用成员时返回时段错误。提供给客户端的模型发现清单会暂时隐藏没有可用成员的复合模型，时间生效后自动恢复。

0.6.764 起，映射卡片右上角可切换「表达式 / 表单」。0.6.765 起，入口为靠右的小图标按钮，悬停显示「切换到表达式 / 切换到表单」。表达式仅编辑日期与时段，例如 `22:00-08:00,12:00-13:00,2026/09/28-2026/10/07`，不包含模型名或竖线。两种模式共享草稿，切换不保存，仍需点击「应用配置」。无效表达式保留原文，修正后才能切回表单或保存；「取消」恢复已保存内容。中继模型显示友好名称，实际存储和路由继续使用其内部 ID。

存储字段 `activeTimeRanges` 保持字符串兼容，例如 `22:00-08:00,12:00-13:00,2026/09/28-2026/10/07,2026/11/01-2026/11/03`。旧的仅小时段配置继续有效；界面不再要求手写旧的 `public-model=upstream-model|...` 表达式。
