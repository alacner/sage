# 安全与授权方案

在“设置 → 通用”后面的“安全与授权”中管理全局方案。每个方案有名称、说明和独立的审批方式、自动批准范围与高级规则。有效配置自动保存，名称和说明结束输入后保存；无效规则不会写入。保存失败时可重试。

- 默认提供“请求批准”和“帮我批准”，可编辑、复制或添加自定义方案。
- 对话输入区的策略菜单可随时选择方案。首次选择会成为新对话的默认方案，也可以在设置中另行“设为默认”。
- 每个对话保存所选方案的配置副本。更改全局方案不会悄悄更改已有对话；需要应用新配置时，在对话中重新选择该方案。
- 当前默认方案不能直接删除。先选择另一个默认方案，再删除原方案。删除其它方案不会删除对话中保存的配置。
- 老对话继续保留原项目策略，可通过“从项目策略创建”复制到全局方案，再按需选择。
- 策略切换影响尚未执行的后续操作。待执行命令的旧审批会重新校验；已经启动的进程保持启动时的运行边界。
- 普通对话和专家任务均按所属对话读取策略；同一项目里的其它对话互不影响。
- 全局备份的“安全”模块包含方案列表及默认方案选择。

## 场景：开发与聊天使用不同方案

1. 添加“开发专用”，填入说明，配置 AI 预审授权和项目文件批准范围。
2. 添加“聊天专用”，采用请求批准，关闭项目写入的自动批准。
3. 开发对话选择“开发专用”，咨询对话选择“聊天专用”。
4. 开发过程中需要人工逐项确认时，切换到“请求批准”，后续操作采用新策略。

方案配置沿用 Sage 现有的文件、命令和网络边界，运行时沙箱保持开启。
