# 记忆融合

0.6.532 起，全局、项目和对话记忆均支持勾选多条记忆，或按标签选择，再点击“融合所选”。预览会合并正文段落并去重标签，可修改内容与标签后保存；取消不修改数据。

自动融合在新增、编辑和历史清理时运行。正文高度相似沿用现有重复判定；正文相似度达到 0.55 且至少有两个相同标签时，视为相关内容并保留不同陈述。仅标签相同不自动融合。此判定是本地字符相似度，不是大模型语义推理；存在语义冲突时应通过预览人工确认。

手动融合只处理当前作用范围，不把项目或对话规则升级为全局。历史清理同样按层处理，不跨层删除。每次手动融合前备份到该记忆文件所在目录的 `.merge-backups`；备份失败则不融合。写操作串行且使用临时文件原子替换，避免并发覆盖。原有最近五份备份保留策略继续生效。

验证：`npm run test:memory`，包含三种范围、正文保留、标签并集、失效选择、备份与并发写入回归。
