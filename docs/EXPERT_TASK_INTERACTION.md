# 专家团主子任务交互

自 0.6.568 起，子任务按父任务 ID 归入对应执行卡片，同一计划内聚合，原始消息与结果保留。子团队执行中自动展开，完成后收起，点击子任务标题可重新查看；错误自动展开。缺少父任务的消息保留在时间线，不直接丢弃。旧版未记录归属的过程提示仍保留在原位置。

新建子团队从整个计划已使用的成员名字之后继续分配，名字池用尽时添加数字后缀。现有计划保持原名，子任务徽章显示所属主任务成员。拆解提示通过父任务 ID 关联真实成员。审批与澄清按父任务和子任务 ID 定位成员，避免同名任务 ID 指向主团队的另一成员。

验证：`node scripts/test-expert-task-tree.cjs`、`node scripts/test-experts-resume.cjs`。

0.6.570：子任务卡片的正文默认折叠，保留执行摘要，错误仍自动展开。父任务标题承担身份展示，拆分过程不重复角色、姓名和主任务标题。执行计划入口位于排队消息上方，详情行与嵌套间距缩小。
