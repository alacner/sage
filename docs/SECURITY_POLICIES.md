# 安全与授权：审批策略

打开全局设置中的「安全与授权」，查看审批策略列表。普通策略支持新增、复制、修改和删除，可以拖拽左侧手柄排序；聚焦手柄后也可用上下方向键调整。列表顺序同步到对话的安全策略菜单。星标指定新对话的默认策略；默认策略不能直接删除，请先选择其它默认项。删除普通策略需在显示方案名称的弹窗中再次确认；取消会保留方案。

## 完全访问权限

完全访问固定独立显示，使用橙色盾牌、名称和说明提醒：可不受限制地访问互联网和电脑上的文件。在对话中选择或将其设为默认时，会先显示权限和风险确认弹窗；取消不会修改策略。确认后，Sage 文件和网页工具解除路径及网站限制，命令不使用运行时沙箱且自动批准。操作仍受 macOS 账号本身的权限限制。该项不能复制、编辑或拖入普通策略中。

## 编辑普通策略

填写名称、备注，从 18 个盾牌、手势、人物、机器人、智能、互联网与手机等纯图标组成的网格中直接选择图标，并从右侧等高的包含赤橙黄绿青蓝紫七色的常用色块中选择颜色，也可使用自定义颜色选择器。名称、备注的颜色同时用于列表和对话菜单。输入与选择自动保存，无单独保存按钮；非法规则不会保存，保存失败可重试。

### 直接拒绝

配置禁止读取、禁止写入和禁止修改的路径；移除的环境变量；拒绝命令正则；拒绝访问的网站。网站支持 `example.com`、`*.example.com`、`/正则表达式/`。明确配置的拒绝命令正则优先于允许规则，网站拒绝规则优先于网站允许规则。文件规则也会在执行器中检查。

### 直接允许

配置项目内文件修改、沙箱内命令跳过审核，以及系统只读路径、PATH 工具目录、保留的环境变量、命令允许正则和允许的网站。命令允许规则通过拒绝检查后，只授予沙箱内执行权限。普通策略的命令及子进程不能联网；网站规则仅用于网页工具，不会开放 npm、curl 或 Git 的联网能力。

规则输入框清空代表空列表；「恢复默认」才恢复系统默认规则。路径和正则保留大小写。

### 需要审核

选择人工审核，或 AI 预审。AI 预审分别填写「直接拒绝的描述」和「直接允许的描述」，可选择预审模型和超时时间。拒绝描述优先；无法明确匹配、证据不足、请求失败或超时，转人工审核。AI 预审覆盖命令、网页以及通过固定边界检查但尚未直接允许的工具。只有明确允许才执行，否则由人工兜底。

## 场景示例

- **本地开发**：添加「程序开发」，选择审核图标和紫色，允许项目文件修改与本地构建。AI 允许说明填写「允许当前项目的本地测试与构建」；拒绝说明填写「不允许删除源代码或整个项目」。发布、部署、push 等未明确授权的操作转人工审核。即使批准，普通策略也不会开放命令联网。
- **聊天与查资料**：添加「聊天模式」，选择 AI 审核图标，关闭项目文件修改自动批准。在允许网站中加入常用资料站，在拒绝网站中排除私有站点。网页查询可直接使用允许的网站，文件写入仍需确认。
- **安排常用策略**：将「程序开发」拖到普通策略列表第一行并设为默认。新对话默认选中它；已有对话保留各自选择，可以从输入区随时切换。
- **切换时机**：某条命令或一轮对话正在执行时，修改或切换策略不会改变本轮持有的策略快照。下一次开始或恢复执行时，加载所选策略的最新配置。已删除的策略保留在既有对话的快照中，直到用户选择其它策略。

策略列表、顺序、图标、颜色和默认项随配置备份的「安全」模块一起导出与导入。

直接拒绝的文件保护、工具环境、命令规则和网页访问分类分别设有生效开关。取消勾选保留规则内容，但不应用该分类的可配置拒绝规则；固定保护仍生效。旧方案未设置开关时保持启用。

预审模型使用统一的搜索、功能过滤和提供商分组选择器，留空跟随当前会话。模型下拉层独立于设置卡片显示，按可用空间向上或向下展开。


## 0.6.309 决策链路与记录

普通对话（API、Claude CLI、Codex CLI）与专家任务共用决策入口：启用的直接拒绝 → 启用的直接允许 → AI 预审 → 人工审核。拒绝与允许分类都有独立开关；关闭保留编辑内容，但不应用该分类的可配置规则。AI 未开启则跳过；返回不确定、调用失败或超时转人工。完全访问权限是单独选择的执行模式。

WebFetch 未匹配允许列表时进入审核，不再直接拒绝。预审使用完整 URL、工具参数及保存的自然语言说明；网页预审不读取项目脚本。AI 或人工批准产生一次性授权，绑定 URL、项目、当前执行会话和策略；过期、重放或参数变化不能执行。重定向使用手动检查，未授权的新目标不会被请求，会返回需要单独审核的信息。Claude CLI 的文件与网页工具也通过 Sage 执行器实现，原生对应工具关闭；MCP 服务端只执行一次 Sage 审批，避免重复弹出人工审核。

审批不会取消普通模式的固定执行边界：命令及其子进程仍禁止直接联网，文件工具仍受项目范围约束。固定执行边界的失败单独标记为“执行边界检查”，不会伪装成已关闭的可配置拒绝规则。工具环境规则负责剥离变量；日志记录剥离的变量名，不记录值，也不把剥离变量解释为拒绝整条命令。

决策记录从编辑表单移至全局独立页面。方案列表的“决策记录”查询该方案在各项目、各对话中的记录；对话菜单的“当前对话决策记录”查询该对话历次使用不同方案的记录。全局导航入口查询所有记录，可按结果、层级、项目、方案、对话及文本筛选。

新记录写入用户数据目录 decisions.log，按执行上下文记录方案 ID/名称、项目、对话、决策层级、规则分类和理由，不依赖当前窗口选择的项目。只追加写入，10 MB 轮转，保留两份旧文件。查询同时兼容已有项目 .sage/audit.log 与旧全局 audit.log；历史记录缺失的方案或层级标记未知，不反推补填。方案改名或切换不修改已发生事件。

颜色控件提供主题色及深浅梯度、标准色和“更多颜色”原生自定义入口，与左侧 18 个图标区域等高。
