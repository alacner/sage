# 图表与内容图片复制

0.6.537 修复 Mermaid “复制图片”在浏览器剪贴板权限受限时失败的问题。

- 图片转换成功后，先调用浏览器 PNG 剪贴板 API；不可用或被拒绝时，通过 preload 将 PNG 字节交给 Electron 原生剪贴板。不降级为源码、路径或文本。
- Mermaid 与对话内容图片复制共用该写入策略。下载仍输出 PNG，不经过剪贴板。
- 大图自适应降低像素倍率：最大边长 8192 像素，总像素不超过 16 Mi。普通图保留原有高清倍率，长图不因固定放大而超出画布预算。
- 主进程只接受 PNG 字节，限制编码长度、图像尺寸并检查解码结果，不接受文件路径或远程地址。
- 验证：`node scripts/test-image-copy.cjs` 使用真实 Electron，覆盖权限拒绝、缺少 ClipboardItem、长图、PNG 像素内容及非法输入，测试结束恢复原剪贴板的常用格式。
