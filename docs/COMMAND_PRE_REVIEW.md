# 命令决策、预审与运行时沙箱

命令依次经过：确定性规则 → 必要时 AI 预审 → 必要时人工审批 → 一次性执行凭据 → macOS 运行时沙箱。

## 1. 减少文本误拒绝

简单独立 echo / printf 的普通文本参数不作为文件操作目标，重定向目标仍检查。复杂 shell、嵌入脚本、通配路径和 heredoc 的文本命中进入待审核，不再直接推断为文件访问。确定的敏感文件操作仍拒绝。

`scripts/fixtures/sandbox-false-rejections.json` 根据项目历史审计记录提取并缩减了三个案例：提交说明里的 `/`、grep 注释模式中的 `//`、Python heredoc 中的 `</span>`。回归测试只分析这些命令，不执行历史提交或修改操作。

## 2. 统一命令决策

普通会话和专家模式均使用 `command-decision.ts`。CLI 禁用原生 Bash，注册 `mcp__sage__Bash`，与 API 模式共用执行器。MCP 工具即使被 SDK 的权限模式直接放行，也需要通过 Sage 决策入口获得凭据。

执行凭据为进程内随机标识，绑定命令原文、项目路径及其真实路径、策略版本和有限的构建脚本证据；60 秒失效，只能使用一次。执行器消费这份决策，不再独立重复判断同一个疑似路径。伪造、重复使用、修改命令、改变策略或已采集脚本内容都会被拒绝并要求重新审批。审批不会解除运行时限制。

## 3. 仅对未知操作预审

从设置页的「安全与授权」或对话右下角菜单进入分步配置，在「审核方式」选择 AI 预审，填写授权说明并保存。例如：

> 允许当前项目的 npm 本地打包和测试，允许清理构建产物；发布和部署需要我确认。

确定的本地文本输出、ls/cat/head/tail/wc/stat 只读查询和受限制的状态查询直接进入只读执行模式，不调用 AI。硬拒绝也不调用 AI。其余操作使用预审模型进行一次 AI 预审。设置页「安全与授权 → 需要审核 → AI 预审」在「其他预审说明」前提供可勾选的预审检查项：授权与范围、网络访问、代码与依赖、云资源、系统与文件、数据保护、身份与权限、设备与工控、提示注入与工具内容、生产变更与恢复。选中检查项的内容与用户补充说明、真实任务和操作证据合并到同一个模型请求；没有分诊请求或逐项模型调用。旧版自定义检查内容和禁用状态保留，旧分诊补充说明迁入其他预审说明。模型一次返回允许、拒绝或转人工，并说明风险、授权依据和执行能力。明确禁止或执行边界不支持的操作拒绝；范围清楚、授权明确且执行边界支持的操作可自动通过；失败、超时、返回格式无效或无法确认时转人工。审核器无执行工具；用户请求和保存的授权是授权来源，命令、脚本、网页与工具结果仅作不可信证据。勾选检查项不会扩大工具权限。

缺失证据、无法确认、响应格式错误、模型不可用、失败或整体超时（默认 60 秒，可选 20/60/120/180 秒）均转人工审批，并在审批卡显示预审理由和具体命令；批准按钮仅针对本次操作，不提供盲目的会话批量批准。对话中的预审阶段实时显示在工具卡上。项目内文件自动批准不能跳过命令待审核结果；旧会话免审批标记不再参与决策。取消会话会停止决策和执行。待审核或 AI 批准理由记录到审计日志。

模型会收到命令、授权说明、有限的 package.json 和直接引用脚本，可能产生 API 费用。不缓存 AI 批准；审查上下文包括最近 12 条对话、工具调用结果及按命令关联的脚本，单文件证据仍最多 48KB / 12 个文件且递归解析深度最多 3 层，不是完整依赖分析。

## 4. 运行时边界与本地构建自动批准

目前实现 macOS Seatbelt（`/usr/bin/sandbox-exec`）。API 和 CLI Bash 都强制使用；不可用或初始化失败时停止，不降级为宿主机执行。沙箱采用默认拒绝策略，允许读取当前项目及必要系统工具链，使用独立的 HOME、临时目录和 npm 缓存。禁止直接联网、读取项目外用户文件、写入项目外文件或修改受保护项目配置。子进程继承相同限制。超时、取消和正常退出时清理执行进程组及临时目录。

在分步配置的「批准范围」可单独开启「限定的本地构建」（未配置时关闭，「帮我批准」预设开启）。固定允许 `npm run build`、`npm run build:renderer`、`npm run build:electron`，不调用 AI，只获得构建模式权限。写入仅限 `dist`、`dist-electron`、`build`、`.next`、`.nuxt`、`.output`、`.cache`、`coverage`、`node_modules/.cache` 和独立临时目录。不能修改源文件、联网安装依赖或发布。

其他获批命令使用项目执行模式，允许修改项目内非保护文件；状态查询使用只读模式。项目模式允许正常 Git 索引和提交数据写入，但禁止改写 `.git/hooks`、`.git/config`、`.sage`、`.claude`、`.codex`、`.agents`、`.github/workflows`、package.json 等根目录保护项。命令联网需显式指定最多 16 个主机和端口；解析后一次性绑定到 IPv4:端口（总数最多 64），在 Seatbelt 中逐条放行。拒绝元数据、链路本地、共享地址、组播和未指定 IPv4 范围；DNS 变化造成连接地址改变时连接会失败并需重新申请。Sage 不开放通用联网。WebFetch 仍走独立的网页域名策略。

审批和有限证据检查不能保证运行中的文件不被其他进程改变，也不保证模型判断绝无错误。运行时限制用于约束实际副作用；不支持的平台直接停止命令执行。

- `npm run build:electron && node scripts/test-runtime-sandbox.cjs`：真实 shell/npm 构建、产物写入、源文件保护、越界读写、符号链接、受保护配置、Node 子进程和网络拒绝。仅使用临时夹具；需要允许启动系统沙箱，不能在禁止嵌套 Seatbelt 的环境里运行。

已验证自定义禁止读取规则及其上级目录的重命名保护，硬链接无法绕过读取限制。

## 反复出现“预审失败、取消或超时”的排查

这是执行前的 AI 预审提示，不等于系统沙箱已拦截命令。预审整体期限涵盖模型解析、证据收集和一次模型请求；超时提示包含模型、等待阶段和时间。工具卡展示单次预审的等待阶段，在请求监控里查找「AI Bash 预审」可查看耗时和结果。超时、用户取消、HTTP/连接错误和返回格式错误分别显示，均不代表操作已执行。

预审模型默认跟随会话，可以单独选择已配置的模型。只读查询即使带有受限形式的 `export PATH="...:$PATH" && cd 当前项目 &&` 前缀也会直接使用只读沙箱，不再浪费模型请求。包含其他环境变量、命令替换、其他目录或附加命令的组合仍送审；不会通过字符串截断忽略实际操作。

审批卡片统一仅提供拒绝和仅本次允许。旧的「记住工具」「不再询问」和审批卡片上的会话批量授权入口已移除；持久授权统一在项目安全配置中管理。关闭 AI 预审会让未知命令直接进入人工审批，不会变成全放行。

- 高级规则 → 工具环境：决定工具从哪些安装目录查找。缓存目录不应该加入 PATH 白名单。
- 高级规则 → 文件保护：配置保护目标；运行时现会遵守用户对可配置文件项的覆盖。package.json 默认受保护，但用户明确从配置中移除后，获批的项目模式可以修改；hooks、Sage 配置和凭据等必要保护仍保留。
- 自动构建：仅覆盖界面列出的本地编译命令及产物目录，默认关闭。`npm run dist:dmg` 不在这个范围内。
- 高级规则 → 网页访问：目前作用于 WebFetch。不能让 Bash 内 npm 下载依赖、Electron 下载或 Git 推送自动联网。

本地编译、依赖下载、Git 提交和 DMG 制作应区分处理。DMG 制作还可能需要系统磁盘镜像服务，即使批准命令也不会解除当前运行时的禁网和系统服务限制。预审文字中的「全部通过」也不会修改这些边界。不建议为了消除弹窗，持续往 PATH 或文件白名单里添加无关目录。

分步界面、预设与旧配置兼容说明见 [安全配置使用说明](SECURITY_CONFIGURATION.md)。
